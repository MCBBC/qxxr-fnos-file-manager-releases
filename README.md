# 文件管理器 · fnOS 发布仓库

本仓库仅保存文件管理器的版本索引、更新日志及 Releases 安装文件，不包含应用源码或用户数据。

- 应用安装包：Releases 中的 `qxxr-file-manager-版本-x86.fpk`（或 arm）。
- 插件更新包：Releases 中的 `插件ID-版本.fmp`。
- 更新入口：应用设置 → 关于 → 检查在线更新。
- 完整日志：`changelog.json`；当前版本和包的 SHA-256：`version.json` 与 Releases 的 `SHA256SUMS`。

首次启用在线更新需手动安装包含“在线更新”插件的新应用版本。后续升级由管理员在应用中确认，通过飞牛应用中心安装；安装期间请先完成文件操作。
